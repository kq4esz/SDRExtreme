# SDR Extreme 0.8.0

## MeshCore support across node models

- Replace Heltec V3-specific setup with a device-neutral companion client.
- Include 94 board profiles from the official MeshCore companion-v1.18.0
  release, including Heltec, LilyGO, RAKwireless, Seeed, ThinkNode, Waveshare
  and other manufacturers. Radio/display variants have separate profiles.
- Keep **Auto / other compatible node** for compatible unlisted boards and
  custom builds, using the same companion protocol.
- Offer each profile's available USB serial, Bluetooth LE and Wi-Fi/TCP
  interfaces. Profiles without Wi-Fi use their supported USB and/or Bluetooth
  interface. USB-only hardware is not incorrectly given Bluetooth capability.
- Provide firmware-aware connection guidance, including custom-build-only
  interfaces, USB CDC/bootloader hints, and detailed serial port identification.
- Display the connected node's reported hardware model and firmware version.
- Expand BLE discovery to accept MeshCore service advertisements and node-name
  prefixes. Optional **Show all Bluetooth devices** supports custom names; the
  MeshCore GATT service and companion handshake are still required.
- Native USB serial and Windows Bluetooth connections require no external
  MeshCore application or Python client. Existing compatible firmware, including
  1.17.1, continues to use the same protocol.
- Include an offline device/transport table, upstream provenance, license,
  and a catalog maintenance command for later app releases.

The selected interface must be enabled by the installed companion firmware.
Repeater/room-server roles and bootloaders do not automatically expose the chat
protocol. No firmware is flashed and no device role is changed by this update.
Catalog coverage does not mean every physical model has been bench-tested.

Use **Help → Check for updates**, restart, then choose your node model in
**MeshCore**. Existing memory channels, radio settings, chats and unread state
are preserved. The installer remains unsigned.

# SDR Extreme 0.7.0

## MeshCore client

- New MeshCore workspace, also available with Ctrl+5.
- USB serial connection at 115200 baud, with COM port discovery.
- Bluetooth LE connection with device selection and PIN pairing in the desktop app.
- Wi-Fi connection to a MeshCore companion TCP service (default port 5000).
- Node identity, LoRa settings, battery voltage, channels and contacts.
- Channel and direct text messaging with UTF-8 limits and accurate send/ACK status.
- Bounded local message history, isolated by node identity; no saved channel keys or PINs.
- Serialized commands, connection cancellation, timeouts and manual reconnection.
- SerialPort's Windows native dependency is included in the installer dependency audit.

Designed for MeshCore companion nodes including Heltec V3. Transport availability
depends on the installed firmware build. Configure channels and contacts with an
existing MeshCore companion app, then sync them in SDR Extreme. Repeater/room
administration, node flashing and radio configuration are not part of this release.

Build validation does not establish physical-node compatibility or RF delivery.
The Windows installer remains unsigned; no signing certificate has been provided.

## Installed receiver startup and dependency fixes

- Fix the USB worker's first-sample native crash under Electron. IQ callbacks
  now copy driver memory into JavaScript-owned buffers compatible with V8.
- Bundle the Windows x64 Koffi native dependency explicitly, plus Visual C++
  runtime sidecars for the application and RTL-SDR DLL.
- Audit all packaged native imports and pinned decoder hashes at build time.
- Clear the HD startup flag before returning the HTTP response, so a stale
  response cannot leave HD controls stuck on **Please wait** after tuning.

The installed desktop's Start listening action was exercised on this PC
with an RTL-SDR Blog V4, followed by reception of WQUT 101.5 MHz HD1. Source
and installed-package USB startup paths use the same supported memory copy.

Download **SDR-Extreme-Setup-0.6.2-x64.exe**, or use **Help → Check for updates**
and close the app after the download is ready. Memories and settings are
preserved. This release remains unsigned.

# Signal Outpost 0.16.13

## Preserve digital modes when importing RadioReference conventional channels

- Resolve RadioReference's mode IDs to their labels before choosing a receiver mode.
- Detect YSF / Yaesu Fusion / C4FM, M17, P25, DMR, NXDN, and D-STAR from mode and channel metadata.
- Correct already imported RadioReference channels to digital mode when a county is imported again.
- Include Windows, Linux AppImage / tar.gz, and Arch Linux packages in this release.

# Signal Outpost 0.16.1

This Linux hotfix corrects the receiver-service startup check when the Linux user-data path contains uppercase characters, including the default `Signal Outpost` folder name. The Linux desktop package and native decoder runtimes are rebuilt for this release.

Linux x64 packages target Ubuntu 22.04 and newer compatible distributions. Please report your Linux distribution, desktop environment, RTL-SDR model, and any startup or reception errors.

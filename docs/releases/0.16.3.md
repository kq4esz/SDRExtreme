# Signal Outpost 0.16.3

## Arch Linux package

- Add an x86_64 Pacman package for Arch Linux and Arch-based distributions.
- Declare the Arch RTL-SDR, USB, GTK, and audio runtime dependencies in package metadata.
- Build the package and pinned HD Radio / DSD-neo runtimes in an Arch Linux release environment.

Install the downloaded package with:

```sh
sudo pacman -U ./Signal-Outpost-0.16.3-x86_64.pkg.tar.zst
```

The package installs the `rtl-sdr` system dependency for analog and HD Radio RF access. Linux USB access remains governed by the distribution's device permissions. This Arch package is x86_64 only.

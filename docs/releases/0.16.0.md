# Signal Outpost 0.16.0

## Linux desktop packages

- Add Linux x64 AppImage and portable tar.gz downloads.
- Include HD Radio through a Linux build of nrsc5 and integrated DSD-neo built from pinned upstream sources.
- Bundle the decoder libraries needed by those modes and build release packages on Ubuntu 22.04 for a broad glibc baseline.
- Keep analog RTL-SDR reception on the distribution's `librtlsdr`; USB access follows the distribution's udev rules.

Linux packages are ready for field validation. Please report your distribution, desktop environment, RTL-SDR model, and any reception or startup errors.

# Signal Outpost 0.16.14

## Scan selected memories and stop live RF with the scan

- The Live Radio scan button now scans only the memory channels selected in Memory Channels, including supported digital memories and trunked systems.
- Mixed conventional and trunked selections are rejected with a clear message.
- Stopping a scan now stops the active receiver or decoder and clears live audio.
- Starting a wide survey from an active scan keeps the receiver open for the survey.
- Include Windows, Linux AppImage / tar.gz, and Arch Linux packages in this release.

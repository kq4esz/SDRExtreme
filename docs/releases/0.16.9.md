# Signal Outpost 0.16.9

## Faster trunked site control-channel scanning

- Add 1, 2 and 3 second dwell options when scanning saved trunked control frequencies; default to 2 seconds.
- Accept 1 second as the minimum server-side dwell. Decoder and tuner startup time adds to each frequency visit.
- Include Windows, Linux AppImage / tar.gz, and Arch Linux packages in this release.

# Signal Outpost 0.16.10

## Keep the tuner open during trunked control-channel scans

- Retune control frequencies through DSD-neo's RTL control API instead of stopping and restarting the decoder and RTL-SDR USB stream on every hop.
- Reload each site's channel and talkgroup maps while the session stays open.
- Require matching decoder profiles within one scan; scan systems with different protocol settings separately.
- Include Windows, Linux AppImage / tar.gz, and Arch Linux packages in this release.

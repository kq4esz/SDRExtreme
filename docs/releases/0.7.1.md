# SDR Extreme 0.7.1

## MeshCore conversation tabs and unread messages

- Separate **Channels** and **Contacts** tabs, with category-specific search.
- Remember the selected conversation and unsent drafts when switching tabs.
- Show unread message counts beside individual channels and contacts.
- Show category totals on both tabs and an overall count beside MeshCore in
  the main application navigation, including its compact layout.
- Save unread state with local message history, separately for each node.
- Clear unread counts when viewing the latest messages in the visible,
  focused conversation. A **N new messages ↓** button jumps to new messages
  while reading older history.
- Preserve messages arriving during a read acknowledgement as unread until
  they are displayed. Sent messages and delivery receipts do not raise counts.

History saved before this update starts as read. Waiting messages retrieved
after the update count as new. This update preserves receiver settings,
memory channels and MeshCore history. Use **Help → Check for updates** and
restart after the download is ready.

# Signal Outpost 0.16.2

## Linux decoder startup fix

- Build the bundled RTL-SDR library with kernel-driver detachment enabled. This lets DSD-neo open RTL-SDR devices when Debian's `dvb_usb_rtl28xxu` kernel module has claimed the USB interface.
- No manual kernel module blacklist is needed for the decoder to attempt device access. Linux USB permissions still follow the installed system's udev configuration.

Use **Help → Check for updates**, then restart to install this version. Linux users can download the AppImage or tar.gz package from the GitHub release.

# Signal Outpost 0.16.4

## RTL-SDR model compatibility

- Use the pinned RTL-SDR Blog V4-compatible driver by default for Linux live analog and HD Radio reception, matching integrated DSD-neo.
- Support RTL-SDR Blog V1, V2, V3 and V4 dongles on Linux and Windows x64. Hardware-specific capabilities such as HF sampling and bias tee depend on the dongle revision.
- Keep the optional custom RTL-SDR library setting and `RTLSDR_LIBRARY` environment override.

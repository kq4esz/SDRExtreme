# Signal Outpost 0.16.15

## Import RadioReference NXDN channel modes correctly

- Recognize RadioReference's contiguous `NXDN48` and `NXDN96` mode labels as digital NXDN instead of falling back to NFM.
- Preserve the NXDN48 or NXDN96 air interface setting for decoder use.
- Correct previously imported RadioReference memories when a later import identifies a digital protocol or a different NXDN air interface.
- Include Windows, Linux AppImage / tar.gz, and Arch Linux packages in this release.

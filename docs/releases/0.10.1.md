# SDR Extreme 0.10.1

## MeshCore channel send policy

- Stop channel sends immediately after the local node accepts a broadcast.
- Retry a channel message only after an explicit node send error, with bounded
  backoff and at most four attempts total.
- Keep the original timestamp across rejected attempts. Remove scheduled repeat
  broadcasts after successful node acceptance.
- Stop on disconnects, timeouts, ambiguous local responses or local destination
  validation failures rather than repeating a possibly queued broadcast.
- Update the channel composer guidance and delivery documentation.

Direct messages retain up to four attempts and stop on a recipient ACK. Existing
receipt and path history remains available. Channels continue to display
recipient delivery as unavailable because the protocol supplies no member ACKs.

Use **Help → Check for updates**, then restart to install this version.
The Windows installer remains unsigned.

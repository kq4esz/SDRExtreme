# SDR Extreme 0.10.0

## MeshCore delivery receipts, retries and paths

- Retry direct chat messages up to four times, stopping as soon as a matching
  recipient ACK arrives. Keep retries in one chat entry and accept late ACKs
  from earlier attempts.
- Record each attempt, node acceptance, receipt time, ACK code and round trip.
- Recover from a stale known route with flood discovery after two ACK timeouts.
- Request four channel broadcasts spaced twenty seconds apart, within four
  total attempts. Fresh timestamps can produce duplicate messages in other
  clients. Channels do not support recipient ACKs, so their delivery remains
  explicitly unconfirmed.
- Add **Receipt & path** to sent messages, with per-attempt route snapshots,
  available relay counts and hashes, known node names and identity ambiguity.
- Show learned routes near delivery and observed ACK return paths separately.
  Native ACKs do not include a complete verified forward path; unavailable
  details remain unknown instead of being inferred.
- Save receipt and attempt history locally. Stop pending sends on disconnect
  or restart, without silently resuming old messages after reconnecting.
- Keep repeater administrative commands on their existing reply workflow,
  without automatic replay of configuration changes.

Use **Help → Check for updates**, then restart to install this version.
The Windows installer remains unsigned.

# SDR Extreme 0.9.0

## MeshCore repeater login over LoRa

- Select a repeater in **Contacts** and use **Connect & log in** through your
  connected USB, Bluetooth or Wi-Fi companion node.
- Confirm login from the selected repeater's response, with administrator,
  guest and legacy access indicators and direct/relayed/flood route details.
- Request battery, uptime, RSSI/SNR, noise floor, queue and packet statistics.
- Send administrator CLI commands and receive replies in a dedicated console.
- Prepare common commands with Version, Clock and Radio settings shortcuts.
- Keep credentials and new command/reply logs out of saved chat history.
- End the app session and clear console/login state without disconnecting the
  companion. Companion disconnects clear all repeater sessions automatically.
- Keep companion message retrieval available while awaiting remote replies.
- Match replies to the selected repeater, bound timeouts and avoid automatic
  retries of commands that may already have executed.

This feature accesses repeater contacts over LoRa. Repeater USB console and
room-server login are separate features. Ending an app session does not revoke
the companion's persistent repeater ACL authorization.

Use **Help → Check for updates**, then restart to install this version.
The Windows installer remains unsigned.

# SDR Extreme 0.8.1

## Organize MeshCore conversations

- Drag channel and contact entries by their **⋮⋮** handle to rearrange them.
- Star favorite channels and chats, with a **Favorites** filter in each tab.
- Pin conversations to a dedicated **Pinned** section at the top of the list.
- Arrange pinned entries too. Dropping into the other group pins or unpins
  the dragged conversation to match the destination.
- Drag the **Channels / Contacts** tabs to swap their order.
- Use **Alt+Up / Down** on a drag handle or **Alt+Left / Right** on a tab
  to rearrange with the keyboard.
- Save ordering, favorites, pins and tab positions separately for each node.
- Preserve hidden entries when rearranging a searched or filtered list.
- Keep unread totals across filters, and retain the active conversation and
  drafts when organizing. Incoming messages do not interrupt an active drag.

Use **Help → Check for updates**, then restart to install this version.
The Windows installer remains unsigned.

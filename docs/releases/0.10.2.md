# SDR Extreme 0.10.2

## Automatic update startup and recovery

- Check for updates immediately, before starting the receiver service.
- Show a startup screen with download progress; automatically install and reopen
  an available stable update before the receiver opens.
- Allow **Open SDR Extreme now** to continue downloads in the background. Slow
  checks (12 seconds) or downloads (two minutes) also open the app automatically.
- Show an in-app update notice with progress, installed/available versions,
  errors, and a **Restart and install** button for background downloads.
- Check hourly while open. Retry failures after 1, 5, 15, then 30 minutes, and
  check again after Windows resumes or the app regains connectivity.
- Handle background download rejections and record retry times in update state.
- Preserve normal-exit installation and stop the receiver before a restart.
- Include the startup screen and updater files in the Windows package audit.

### Existing clients must receive this fix first

Versions through 0.10.1 silently download after a 15-second startup delay and
install on normal exit. Choose **Help → Check for updates**, wait for the
download, then **Help → Restart to install update**. If that fails, close SDR
Extreme and run **SDR-Extreme-Setup-0.10.2-x64.exe** over the existing installation
using the same Windows account/folder. Memories, settings and MeshCore history
are preserved. No uninstall or deletion of saved data is needed.

The corrected automatic startup installation applies to subsequent updates.
The Windows installer remains unsigned.

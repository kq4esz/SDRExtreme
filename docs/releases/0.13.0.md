# Signal Outpost 0.13.0

## MeshCore node advertisements

- Add **Advert Zero Hop** and **Advert Flood Routed** below the local node
  information, in a new **Advertise your node** section.
- Zero-hop adverts announce the companion locally without repeater forwarding.
  Flood-routed adverts can be relayed by repeaters within the node's existing
  default flood scope.
- Use the companion's existing configured identity and location policy over
  USB, Bluetooth LE or Wi-Fi, through its native self-advertisement command.
- Show queued/sending state, node acceptance and rejection or uncertain results.
  Local acceptance does not confirm reception by remote nodes.
- Serialize requests with other companion commands, prevent concurrent duplicate
  requests, and bind queued operations to the original node and connection.
- Send an advert only when a user clicks its button. Do not automatically
  advertise on startup, connection, refresh or reconnect, or automatically retry
  a request after a lost reply or node error.

Use **Help → Check for updates**, then restart to install. Build/package checks
do not transmit advertisements. Live radio operation has not been exercised.
The Windows installer remains unsigned.

# Signal Outpost 0.15.0

## New Propagation workspace

- Add **Propagation** to the sidebar and a desktop **Ctrl+6** shortcut.
- Show NOAA space-weather scales, Kp and solar flux, with HAMQSL / N0NBH
  calculated day/night HF band outlooks and solar observations. Display source
  timestamps, provider refresh intervals, and missing or stale-data notices.
- Add an ISS ground-track map and observer geometry from CelesTrak GP elements
  using satellite.js SGP4. Address search or direct coordinate entry supports a
  saved observer, height and minimum elevation.
- Calculate upcoming ISS radio passes over 3, 5 or 7 days, including rise,
  peak, set, azimuth, maximum elevation and a live countdown. Use UTC or the
  computer's local timezone. Optical visibility and terrain are not modeled.
- Add PSK Reporter FT8/FT4 activity for a chosen callsign or receiver grid,
  with sampled reception paths, band/mode filters and a report table. Respect
  the five-minute provider query interval and label saved data.
- Include the shared receive-only WSJT-X UDP bridge, normalize FT8/FT4 modes,
  use recent Status messages for RF frequency, and label replay, low-confidence
  and audio-file decodes. Report UDP bind errors before declaring the bridge
  started. Provide a common USB dial-frequency reference with copy buttons.
- Keep location preferences local, perform address searches only on request,
  and isolate pass prediction work from the receiver service's event loop.
- Include the workspace in both Light and Dark appearances and extend the
  installer dependency audit to its new modules and orbital library.

Use **Help → Check for updates**, then restart to install. The installer remains
unsigned. Syntax, build and package checks were performed. Interactive visual,
live WSJT-X/receiver and observed ISS-pass checks were not run for this release.

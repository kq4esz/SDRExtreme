## Install

Download **SDR-Extreme-Setup-0.6.0-x64.exe** and run the installer. Start SDR
Extreme from the desktop or Start menu. Node.js and command scripts are not
required on the receiving PC. Windows 10/11 x64 and a supported RTL-SDR with
WinUSB on Bulk-In Interface 0 are required for local USB reception.

This build is unsigned; Windows SmartScreen may display an unknown-publisher
warning. `SHA256SUMS.txt` provides file checksums.

## Included

- Complete desktop receiver with native RTL-SDR USB, HD Radio and FM fallback.
- P25 Phase 1/2, NXDN48/96 and other integrated digital voice modes.
- Spectrum/waterfall, scanner memories, KiwiSDR map, CW and WSJT-X bridge.
- Automatic GitHub release checks at launch and every four hours.
- Automatic background update downloads, installed after normal app exit.
- Help menu controls to check updates and restart when an update is ready.
- Memories/settings stored outside the application installation in
  `%APPDATA%\SDR Extreme\data`, preserved across updates.
- Queued asynchronous USB transfers and HD gain/buffering improvements from
  the live WQUT 101.5 MHz reception checks.

Source, licenses and native component source snapshots are included in this
repository and the installed package. The USB driver installation remains a
separate Windows hardware setup step.

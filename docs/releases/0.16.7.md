# Signal Outpost 0.16.7

## Waterfall behavior adjustment

- Remove the 20 MHz stepped sweep control from Live Radio and Decoders. Live RTL-SDR waterfall width continues to reflect the bandwidth captured by the connected receiver.
- Keep click-to-tune snapping to the selected frequency step and retain the existing 0–2.4 GHz Wide survey.
- A simultaneous live span wider than the RTL-SDR capture bandwidth requires a supported wideband receiver.
- Include updated Windows, Linux AppImage / tar.gz, and Arch Linux packages.

# Signal Outpost 0.14.0

## Light and dark appearance

- Add a **Light mode** switch beside **Settings** in the sidebar. The visible
  label shows the active mode; keyboard and screen reader users can operate
  the same switch. It remains available when the sidebar becomes compact.
- Keep the existing appearance as the default dark mode. The original dark
  application and MeshCore styles are unchanged.
- Add a light palette for navigation, radio, HD Radio, memory channels,
  decoders, MeshCore conversations and repeater controls, dialogs and notices.
- Match RF spectrum grids and traces to the selected theme, preserve waterfall
  signal colors, and display the KiwiSDR directory map in its normal light
  colors with contrasting station markers. Remote KiwiSDR listening interfaces
  keep their receiver-provided appearance.
- Save the selected mode in the app profile's browser storage and apply it
  before styles load on the next launch. Dark mode remains the fallback if
  storage is unavailable. Theme changes do not reconnect or retune receivers.
- Build the light color overrides from the existing application styles during
  packaging so newly added panels receive the same palette.

Use **Help → Check for updates**, then restart to install. The Windows installer
remains unsigned. Build and package checks were performed; interactive visual
and receiver operation checks were not run for this release.

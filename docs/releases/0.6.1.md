## Start listening crash fix

- Fix the native USB worker aborting as soon as its first IQ samples arrive
  in the installed Electron application. Native samples now copy into
  JavaScript-owned memory, compatible with Electron's V8 memory cage.
- Bundle the Visual C++ runtime beside the application executable and the
  RTL-SDR DLL so receiver startup does not depend on a separate runtime
  installation on the receiving PC.
- Explicitly include the Windows x64 Koffi native dependency.
- Audit the packaged native dependencies and pinned decoder hashes during
  each installer build, before a release can be published.

Install **SDR-Extreme-Setup-0.6.1-x64.exe**, or use **Help → Check for updates**
in 0.6.0 and close the app once the download is ready. Memories and settings
are preserved. This release remains unsigned.

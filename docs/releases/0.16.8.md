# Signal Outpost 0.16.8

## Trunked site control-channel scanning

- Select saved trunked systems in the Memory channels scanner. The scan plan includes each saved site's primary and alternate control frequencies.
- Rotate through those control frequencies with a configurable 5–30 second dwell, using the integrated DSD-neo decoder to report control-channel lock and active calls. Hold on decoded calls until they end, then resume after the selected hang time.
- Show the current system, site, frequency and decoder activity in scan status. Skip advances to the next control frequency; Stop ends the scan.
- Keep trunked-system selection separate from conventional memory scanning. A single RTL-SDR checks frequencies sequentially and may miss activity while tuned to another site.
- Include Windows, Linux AppImage / tar.gz, and Arch Linux packages in this release.
